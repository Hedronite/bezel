# bezel-bridle

Bridle for a coding harness. Not the harness, and not the crates.io crate [`bezel`](https://crates.io/crates/bezel) (a gpui component library).

`0.1.0` reserves the name. It decides code-deny flags, the `0.4` write-concern bar, and an empty check that never approves. It does not call a model and it does not exec an agent.

The JavaScript prototype remains the oracle until the Rust port matches it. Bend laws ship as a skill in the Bezel pack. Proofs follow the modules they check.
