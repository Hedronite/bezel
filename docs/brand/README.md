# Bezel brand

Identity art for Bezel, a Hedronite setting. Built by [VirtualMachinist](https://github.com/VirtualMachinist). Navy field, gold ring, copper wordmark.

| File | When to use it |
| --- | --- |
| [`bezel-lockup.png`](bezel-lockup.png) | Stacked lockup. Gem in a gold ring, the wordmark, and the tagline "a Hedronite setting". README hero and other portrait locks. |
| [`bezel-horizontal.png`](bezel-horizontal.png) | Horizontal lockup. Icon on the left, wordmark on the right. Wide headers. |
| [`bezel-wordmark.png`](bezel-wordmark.png) | Wordmark only. Copper "bezel" on navy. Places that already show the icon, or where type is enough. |

## Usage

- Keep the navy field. These files are not cutouts.
- Shield colors from the lockup: navy `#0a1420`, gold `#c5a378`. Nix and Node badges may keep their native accents on that same navy rail.
- Do not pair this art with Omarchy or oh-my-pi logos in a way that implies those projects ship Bezel.
- Launch stays quiet. These files are documentation art. They are not printed at startup.
