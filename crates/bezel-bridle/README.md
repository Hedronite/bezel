# bezel-bridle

Bridle for a coding harness. Not the harness, and not the crates.io crate [`bezel`](https://crates.io/crates/bezel) (a gpui component library).

`0.2.1` is the current release. `0.2.0` and `0.1.0` stay published and their git tags are not moved. `bezel-bridle --version` prints `bezel-bridle 0.2.1`. Secret paths now include keys and credentials, not only `.env`. A write that carries flags reports `writer_parent`. The crate still does not call a model and it does not exec an agent.

The JavaScript prototype remains the oracle until the Rust port matches it. Bend laws ship as a skill in the Bezel pack. Proofs follow the modules they check.
